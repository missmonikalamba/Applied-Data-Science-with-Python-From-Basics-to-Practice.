# Module 1: Foundations of Data Manipulation

**Duration:** Week 1 · **Theory:** 2 hrs · **Practical:** 3 hrs · **Total:** 5 hrs  
**Prerequisites:** Basic Python programming (variables, loops, functions, lists)

This module introduces the two libraries that almost every Python data project starts with: NumPy for fast numerical arrays and Pandas for labelled, table-shaped data. It closes with reading and writing data in CSV, Excel and JSON formats.

## Learning outcomes

By the end of this module, learners will be able to:

- Create and manipulate NumPy arrays using core functions
- Perform arithmetic, aggregation, and comparison operations on arrays
- Use indexing, slicing, boolean indexing, and fancy indexing
- Import, explore, and manipulate data using Pandas Series and DataFrames
- Read and write data in CSV, Excel, and JSON formats
