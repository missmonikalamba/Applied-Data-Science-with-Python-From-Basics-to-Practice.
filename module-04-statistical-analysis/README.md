# Module 4: Statistical Analysis with Python

**Duration:** Weeks 5–7 · **Theory:** 6.5 hrs · **Practical:** 9.5 hrs · **Total:** 16 hrs  
**Prerequisites:** Modules 1–3 completed

Statistics turns charts into evidence. This module covers descriptive statistics, sampling and estimation, correlation, hypothesis testing with SciPy, and simple linear regression with statsmodels, with the emphasis on interpreting results in plain language.

## Learning outcomes

By the end of this module, learners will be able to:

- Calculate and interpret measures of central tendency and variability
- Understand and apply probability distributions
- Perform hypothesis testing with t-tests, chi-square, and ANOVA
- Calculate and interpret correlation and regression coefficients
- Use SciPy and StatsModels for statistical computation
