# Module 5: Machine Learning

**Duration:** Weeks 8–10 · **Theory:** 4 hrs · **Practical:** 8 hrs · **Total:** 12 hrs  
**Prerequisites:** Modules 1–4 completed

This module introduces machine learning with scikit-learn: the ML pipeline and train/test split, supervised learning for classification and regression, unsupervised clustering with K-Means, and practical tools such as feature scaling and pipelines. It runs over three weeks with extra guided practice and leads into the Final Project.

## Learning outcomes

By the end of this module, learners will be able to:

- Define machine learning and describe its types and applications
- Build and evaluate a supervised learning model (classification and regression)
- Apply clustering as an unsupervised learning technique
- Implement Linear Regression and Logistic Regression using scikit-learn
- Evaluate models using appropriate metrics (accuracy, RMSE, confusion matrix)
